# eaty

Помогает решить, что поесть:

- **Веб-приложение (на телефоне на кухне):** рецепты на каждый день с таймером на
  каждый шаг, план на неделю, список покупок с ценами из Wolt и учёт продуктов дома.
  Заказы из Wolt попадают туда сами через расширение для Chrome.
- **CLI `eaty`:** открытые рестораны Wolt не дальше 1 км с хорошим рейтингом.

## Веб-приложение

Стек: FastAPI, SQLAlchemy 2.0 (async, asyncpg), миграции Alembic, PostgreSQL.
Фронтенд — один статический SPA без сборки (`eaty/web/static`), поэтому его не надо собирать.

```
eaty/
  recipes_data.py      рецепты (на 2 порции), продукты и меню недели — источник правды
  shopping.py units.py catalog.py   чистая логика: список покупок, единицы, разбор каталога
  web/
    app.py             фабрика FastAPI, lifespan (миграции + сид), запуск `eaty-web`
    db.py models.py schemas.py seed.py
    routers/           plan, recipes, shopping (+ каталог), pantry (+ заказы Wolt)
    services/          catalog (цены из Wolt), orders (импорт заказов), pantry (учёт)
    migrations/        Alembic
extension/             расширение Chrome: заказы с wolt.com -> приложение
```

### Запуск

```bash
python -m venv .venv
.venv\Scripts\pip install -e ".[dev]"
```

Настройки в `.env` (в git не попадает):

```ini
POSTGRES_URI=postgresql+asyncpg://user:password@host:port   # сервер; драйвер можно не указывать
EATY_DB_NAME=eaty                                           # база на этом сервере
# или сразу: EATY_DATABASE_URL=postgresql+asyncpg://user:password@host:port/eaty
```

Базу один раз создать на сервере (psql спросит пароль):

```bash
psql -h <host> -p <port> -U <user> -d postgres -c "create database eaty"
```

Запуск. При старте приложение само накатывает миграции (`alembic upgrade head`)
и заполняет рецепты:

```bash
.venv\Scripts\eaty-web
```

Открыть: http://localhost:8000.

Миграции вручную: `alembic upgrade head`, новая миграция после правки моделей —
`alembic revision --autogenerate -m "что поменялось"`.

### С телефона

Приложение слушает только `127.0.0.1`. На телефон его удобно отдать через Tailscale,
он раздаёт по HTTPS только в твою сеть Tailscale:

```bash
tailscale serve --bg 8000
```

Адрес вида `https://<компьютер>.<tailnet>.ts.net`. HTTPS нужен, чтобы во время таймеров
экран не гас (Wake Lock) и приходили уведомления.

### Расширение для заказов из Wolt

1. `chrome://extensions` → включить «Режим разработчика» → «Загрузить распакованное» →
   папка `extension`.
2. Если приложение открыто не на `http://localhost:8000`, впиши адрес в окошке расширения.
3. Открой на wolt.com историю заказов или сам заказ: продукты попадут в «Дома».

Расширение не читает ни cookie, ни токены. Оно смотрит на данные, которые сайт Wolt
сам загружает для страницы заказа, находит в них заказ (id, статус, позиции) и
отправляет в приложение без адресов и телефонов. Формат у Wolt внутренний и
недокументированный, поэтому разбор сделан по форме данных, а не по точным полям.
Корзины и отменённые заказы пропускаются, а повторная отправка того же заказа ничего
не удваивает.

### Как считается

- **Рецепты** на 2 порции. «×2» в плане значит приготовить двойную порцию: половина на
  обед завтра. Курица с картошкой готовится в аэрогриле (духовки нет), остальное на плите.
- **Покупки** = ингредиенты неприготовленных блюд за N дней минус то, что дома. Для
  каждого продукта берётся привычный товар, а если его нет в наличии — самый дешёвый
  за кг, л или штуку среди подходящих по названию. Упаковки округляются вверх.
- **Цены** берутся из открытого поиска Wolt, без логина: кнопка «Обновить цены из Wolt».
- **Дома** ведётся как журнал: заказ добавляет, «Приготовлено» списывает, ✎ поправляет.

## CLI: рестораны рядом

```bash
eaty                              # лучшие рестораны в радиусе 1 км с рейтингом от 9.0
eaty --surprise                   # случайный из топ-5
eaty --tag sushi --tag poke       # только нужная кухня
eaty --min-score 8.5 --radius 1.5 # если рядом мало вариантов
eaty --address "Rustaveli Ave 12, Tbilisi"
eaty --json                       # машиночитаемый вывод
```

Для CLI в `.env` нужны координаты: `EATY_LAT`, `EATY_LON` (или `EATY_ADDRESS`).
Рестораны берутся из того же API, что у wolt.com:
`GET https://consumer-api.wolt.com/v1/pages/restaurants?lat=…&lon=…`, без логина.
Рейтинг — `venue.rating.score` (0–10), расстояние считается по прямой, а «открыт»
значит `online` и `delivers` (флаг `--include-closed` это выключает).

## Тесты

```bash
pytest                              # логика; тесты с базой пропускаются
node --test tests/extract.test.mjs  # разбор заказов в расширении
```

Тесты с базой (миграции, сид, API) запускаются, если задан `EATY_TEST_DATABASE_URL`.
База при этом **стирается**, поэтому нужен локальный сервер или база с `test` в имени.
Без установки Postgres можно поднять его в памяти через PGlite (PostgreSQL в WASM):

```bash
npx -p @electric-sql/pglite-socket -p @electric-sql/pglite pglite-server --db=memory:// --port=5499 --max-connections=8
set EATY_TEST_DATABASE_URL=postgresql+psycopg://postgres:postgres@127.0.0.1:5499/postgres
pytest
```

С PGlite нужен драйвер psycopg: asyncpg с ним не работает. Для настоящего сервера
подходят оба драйвера.
