# eaty

Помогает выбрать, что поесть. Сейчас умеет одно: найти в Wolt открытые рестораны
не дальше 1 км от тебя с хорошим рейтингом и предложить, откуда заказать.

Дальше в планах: меню и блюда, меню на неделю из рецептов, заказ продуктов в Wolt.

## Установка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env   # впиши свои координаты или адрес
```

## Запуск

```bash
eaty                              # лучшие рестораны в радиусе 1 км с рейтингом от 9.0
eaty --surprise                   # случайный из топ-5
eaty --tag sushi --tag poke       # только нужная кухня
eaty --min-score 8.5 --radius 1.5 # если рядом мало вариантов
eaty --address "Rustaveli Ave 12, Tbilisi"
eaty --json                       # машиночитаемый вывод
```

Пример вывода:

## Как это работает с Wolt

У Wolt нет официального API для покупателей. eaty ходит в тот же API, что и сайт
wolt.com: `GET https://consumer-api.wolt.com/v1/pages/restaurants?lat=…&lon=…`.
Для списка ресторанов ни логин, ни ключ не нужны, достаточно координат точки доставки.

- **Рейтинг** берётся из `venue.rating.score` (шкала 0–10, как в приложении).
  Рестораны без рейтинга отбрасываются.
- **Расстояние** считается по прямой от твоей точки до координат ресторана.
- **Открыт** значит `online` и `delivers` в ответе Wolt (выключается флагом `--include-closed`).

Действия с аккаунтом (сохранённые адреса, корзина, заказ, история) потребуют
токен авторизации из браузера. Это следующий шаг.

### Если прямого доступа к Wolt нет

Открой в браузере
`https://consumer-api.wolt.com/v1/pages/restaurants?lat=<широта>&lon=<долгота>`,
сохрани ответ как `page.json` и запусти `eaty --from-file page.json`.

В облачной среде Claude Code домены Wolt по умолчанию закрыты. Добавь `*.wolt.com`
(и `nominatim.openstreetmap.org`, если нужен `--address`) в Network access в
настройках среды.
